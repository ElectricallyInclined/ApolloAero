# MPR-SAT-FE-69-4: Apollo 9 ascent flight conditions

[Figure 4-4 CSV](Figure4_4_mach_dynamic_pressure.csv) contains 191 sampled Mach and dynamic-pressure points against range time from the AS-504 Apollo 9 *Saturn V Launch Vehicle Flight Evaluation Report* (MPR-SAT-FE-69-4), PDF p. 78. The [overlay](Figure4_4_mach_dynamic_pressure_overlay.png) plots samples over the [2× source-page render](Figure4_4_source.png). The [trace script](trace_figure4_4.py) stores the corrected anchor coordinates, axis calibration, and local curve-following method. Its Python dependencies are `numpy`, `opencv-python`, and `Pillow`.

The full report is available from the [public Apollo archive](https://www.ibiblio.org/apollo/Documents/lvfea-AS504-Apollo9.pdf); it is not duplicated here. Its SHA-256 in the source collection was `ee1c00d5c9c783625dd5dd364037fc3c8f369fcea7573b239fac9372d14e5b41`. This folder contains only the aero-relevant Figure 4-4 trace, not the other launch-vehicle plots from the report.

Mark checked the CSV against its revised overlay on **2026-10-10**. The exact reviewed hash and scope are in the [public registry](../DATASETS.json). This plot is a launch-vehicle **flight-condition** reference, not a command-module force or moment coefficient. The two series have separate y-axis units (`1` for Mach and `N/cm^2` for dynamic pressure). Plot-derived points are estimates; source-table event values still need checking before precise simulation calibration. Running the script may replace the reviewed CSV, so verify its hash afterward and seek a new review if it changes.
